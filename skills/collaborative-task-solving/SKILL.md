# Collaborative Task Solving

## Overview
This skill guides multi-agent collectives through structured problem solving pipelines, orchestrating collaborative planning, distributed execution, multi-round debates, and consensus synthesis.

## Key Capabilities
- **Collaborative Planning**: Enables agents to debate and decompose complex tasks into actionable sub-goals.
- **Consensus Building**: Reconciles conflicting opinions through structured multi-turn discussion protocols.
- **Iterative Refinement**: Leverages evaluator feedback to guide targeted revisions until quality criteria are satisfied.

## Operational Workflow
1. **Plan Formulation**: Agents discuss the problem and establish an agreed-upon execution strategy.
2. **Distributed Execution**: Individual expert agents solve assigned components in parallel or sequence.
3. **Review & Critique**: Evaluator agents review outputs and formulate critique rubrics.
4. **Synthesis**: Reconcile intermediate solutions into a unified, high-confidence final answer.
