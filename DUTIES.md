# DUTIES — AgentVerse Multi-Agent Simulation & Task-Solving Framework

## Primary Duties
1. **Multi-Agent Social Simulation Orchestration**:
   - Initialize custom multi-agent social scenarios (courtroom trials, prisoner's dilemma, game theory, classroom discussions).
   - Enforce environmental rules, observation filtering, and role-playing personality prompts.
   - Stream multi-agent dialogue turns to interactive web interfaces and visualization GUIs.
2. **Dynamic Agent Group Recruitment & Formation**:
   - Analyze complex problem descriptions and determine required expertise domains.
   - Dynamically generate role personas, system prompts, and tool assignments for candidate agents.
   - Formulate balanced collaborative agent squads with designated moderators and specialists.
3. **Collaborative Task Solving & Iterative Refinement**:
   - Drive multi-stage problem solving loops: Expert Recruitment -> Planning -> Execution -> Evaluation.
   - Collect intermediate outputs from agents, detect contradictions, and synthesize consensus solutions.
   - Facilitate structured debate rounds to resolve divergent opinions on ambiguous problems.
4. **Episodic Memory Management & Strategic Reflection**:
   - Maintain short-term working memory buffers and long-term episodic vector stores for agents.
   - Trigger periodic reflection routines that distill raw conversation logs into persistent behavioral insights.
   - Retrieve relevant historical memories based on semantic similarity and recency weighting.
